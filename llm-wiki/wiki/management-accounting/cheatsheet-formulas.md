## 꼭 외워야 할 공식

| 이름 | 공식 | 기억법 |
|---|---|---|
| **예정배부율 (POHR)** | 추정 총 제조간접원가 ÷ 추정 총 배부기준 | 고지서를 기다릴 수 없으니 미리 정해둔 비율 |
| **완성품환산량 (EU)** | 물량 × 완성도(%) | 재료용 · 가공용 **따로** |
| **가공원가** | 직접노무(DL) + 제조간접(MO) | 재료를 제품으로 "바꾸는" 비용 |
| **기초원가** | 직접재료(DM) + 직접노무(DL) | 직접 추적되는 것들만 |
| **원가 방정식** | $Y = mX + b$ | 총원가 = 단위변동비 × 조업도 + 총고정비 |
| **고저점법 기울기** | (최고조업도 원가 − 최저조업도 원가) ÷ (최고 조업도 − 최저 조업도) | **원가가 아니라 조업도(X)**로 고른다 |
| **공헌이익 (CM)** | 매출 − 변동비 | 고정비를 갚는 데 기여하는 돈 |
| **공헌이익률** | 공헌이익 ÷ 매출 | 매출 1원당 남는 비율 |
| **손익분기 수량** | 고정비 ÷ 단위당 공헌이익 | 빚 ÷ 한 개당 갚는 금액 |
| **손익분기 매출액** | 고정비 ÷ 공헌이익률 | 수량 대신 금액으로 |
| **목표이익 수량** | (고정비 + 목표 영업이익) ÷ 단위당 공헌이익 | 빚 + 벌고 싶은 돈 |
| **세후 → 세전 환산** | 목표 영업이익 = 목표 순이익 ÷ (1 − 세율) | £300,000 ÷ 0.75 = £400,000 |
| **안전한계** | 현재 매출 − 손익분기 매출 | 얼마나 떨어져도 버티나 |
| **영업레버리지도** | 공헌이익 ÷ 영업이익 | 매출 변화 → 이익 변화 **배율** |
| **가중평균 공헌이익** | Σ (제품별 배합비중 × 제품별 단위 CM) | 여러 제품을 하나로 합쳐 보기 |
| **재고 만능 공식** | 기초 + 투입 − 기말 = 나간 것 | 원재료 · 재공품 · 제품 세 창고 전부 |

## 시험 직전 5분 체크리스트

- [ ] 재무회계 = 외부·과거·엄격 / 관리회계 = 내부·미래·자유
- [ ] 원가 3형제 = DM · DL · MO, 문제는 언제나 **MO**
- [ ] 제품/기간 구분 기준은 **공장 담장**, 변동/고정과는 **별개의 축**
- [ ] 제품원가는 **팔려야** 비용이 된다 (그전엔 자산)
- [ ] 완성품환산량은 재료·가공을 **따로** 계산
- [ ] 개별원가 = 다 다른 제품 / 종합원가 = 다 같은 제품
- [ ] 고저점법은 **조업도(X)** 기준으로 두 점을 고른다
- [ ] 공헌이익 = 매출 − 변동비 → 고정비 갚고 남으면 이익
- [ ] 세후 목표이익은 **÷ (1−세율)**로 세전 환산 먼저
- [ ] 레버리지가 크다 = 좋다가 아니라 **진폭이 크다**
- [ ] 생산 > 판매면 **전부원가** 이익이 더 크다
- [ ] 모든 예산은 **판매예산**에서 시작한다

> [!summary] Key takeaways
- Machine hours = total time a machine runs.
- Can be recorded as machine‑driven hours or labor hours.
- Serves as a pure measure of equipment usage.

## Definition
- **Machine hours**: the count of hours a machine is operating.
- Also expressed as **labor hours** when work is measured by human effort on the machine.

## Measurement
- Track via machine counters or time‑cards for labor.
- Provides a straightforward, quantitative usage metric.

## Applications
- Used in cost accounting to allocate machine‑related expenses.
- Helps schedule maintenance based on actual run time.

## Key terms
| Term | Meaning |
|------|---------|
| Machine hours | Total operating time of a machine (or equivalent labor hours) |
| Labor hours | Human‑time spent operating or servicing the machine |
| Usage metric | A quantitative measure (like machine hours) for resource consumption |

> [!summary] Key takeaways
> - Build the X‑chart from the first data set; reuse its limits for later shifts.  
> - Points outside control limits signal a possible assignable cause, not a proven effect.  
> - Verify stability before assessing capability (Cp, Cpk).  
> - Cp = (spec width)/(6σ); Cpk accounts for mean offset.  
> - Aim for Cp/Cpk > 1 (ideally > 1.33) to keep defect rates below 0.27 %.

## 1. X‑chart control procedure
- **Sheet 1** provides the initial sample means ( \(\bar{\bar X}\) ) and ranges ( \(\bar R\) ); compute limits with \(A_2\bar R\) as a proxy for \(3\sigma_{\bar X}\).  
- For every later sheet, **do not recompute limits**; plot the new sub‑samples on the same chart.  
- If a point falls outside the limits, treat it as a **signal** to search for an assignable cause.  

> [!warning] Do **not** conclude “effect produced” solely because a point is outside control limits; further investigation is required.

## 2. Variation types
- **Random (common‑cause)** – natural up‑and‑down fluctuation, follows the 68‑95‑99 % σ rules.  
- **Systematic (assignable‑cause)** – trends, cycles, sudden shifts; requires root‑cause analysis (e.g., Ishikawa diagram).  

> [!info] **Special‑cause detection** is the primary goal of SPC; eliminating it restores a stable process.

## 3. Control limits vs. Specification limits
| Type | Meaning | Source |
|------|---------|--------|
| **Control limits (LCL/UCL)** | Intrinsic process capability (±3σ) | Calculated from initial data |
| **Specification limits (LSL/USL)** | Customer‑driven acceptance range | Defined by product requirements |

> [!warning] Confusing the two can lead to mis‑interpreting a point outside control limits as a defect.

## 4. Two‑step SPC approach
1. **Confirm stability** – no assignable causes, chart points within limits.  
2. **Assess capability** – compare stable process spread to specification width (Cp, Cpk).  

> [!example] If the process is in control but Cp = 0.5, the process is too variable to reliably meet specs; improvement must start with reducing σ.

## 5. Process capability metrics
> [!info] **Cp** = \((\text{USL}‑\text{LSL})/(6σ)\) – compares specification width (green line) to total process spread (blue line).  
> [!info] **Cpk** = \(\min(\text{USL}‑μ,\;μ‑\text{LSL})/(3σ)\) – adds the effect of mean shift.

### Cp ↔ defect rate (approx.)

| Cp | Defect rate |
|----|-------------|
| 1  | 0.27 % |
| 2  | 0.027 % |
| 0.5| 2.7 % |

### Worked example
> [!example] **Baseline**: μ = 45 g, σ = 1 g, specs 42–48 g.  
> Cp = (48‑42)/(6×1)=1 → defect ≈ 0.27 %.  
> **Improved**: σ reduced to 0.5 g → Cp = 2 → defect ≈ 0.027 %.  

## 6. Improving capability
- **Raise Cp**  
  - Reduce σ: better equipment, maintenance, training.  
  - Shift μ toward target (improves Cpk).  
- **Lower Cp** (avoid)  
  - Use cheaper, less reliable machines.  
  - Cut training/maintenance.  

> [!warning] Capability numbers are meaningless while the process shows special‑cause variation; stabilize first.

## 7. Exam tip
- When the latest sample mean lies outside control limits, the correct answer is **“no effect”** or **“more information needed,”** not “effect produced.”

## Key terms
| Term | Meaning |
|------|---------|
| **Assignable (special) cause** | Non‑random source of variation that can be identified and eliminated |
| **Control limits (LCL/UCL)** | ±3σ limits derived from a stable process |
| **Specification limits (LSL/USL)** | Customer‑defined acceptable range |
| **Cp** | Process capability ratio; spec width ÷ 6σ |
| **Cpk** | Process capability index; accounts for mean shift |
| **A₂ region** | Formula component approximating 3σ for \(\bar X\) charts |
| **Ishikawa (fishbone) diagram** | Tool for systematic root‑cause analysis |

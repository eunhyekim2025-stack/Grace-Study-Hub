> [!summary] Key takeaways  
- EOQ optimizes order size for deterministic demand using \(Q^*=\sqrt{2KD/H}\).  
- Fixed/sunk costs (e.g., lease) are excluded from EOQ; only holding & shortage costs matter.  
- Newsvendor (uncertain demand) balances overage \(C_o\) and underage \(C_u\) via critical ratio \(CR=C_u/(C_o+C_u)\).  
- Safety stock = \(Z\sigma\) where \(Z\) is the normal quantile matching \(CR\); optimal order \(Q^*=\mu+Z\sigma\).  
- Reducing K or H changes optimal quantity by the square‑root of the cost change, not linearly.

## 1. EOQ model (deterministic demand)

- **Formula**  
  > [!info] \(Q^{*}= \sqrt{\dfrac{2KD}{H}}\) \(K\)= ordering cost, \(D\)= annual demand, \(H\)= holding cost/unit.  

- **Assumptions**  
  - Constant demand \(D\) (no uncertainty).  
  - Fixed ordering cost \(K\) and holding cost \(H\).  
  - Unit price constant (price changes handled separately).  

- **Practical limits**  
  - Estimating \(K\) and \(H\) is hard; they may vary over time.  
  - Mis‑specifying either leads to wrong \(Q^{*}\) and cost ratio \(C/C^{*}\).  

- **Cost ratio behavior**  
  - \(C/C^{*}<1\) if order < EOQ, \(=1\) at EOQ, \(>1\) if order > EOQ.  
  - Example: ordering \(2Q^{*}\) raises total cost by ≈ 3 % (non‑linear).  

- **Square‑root effect**  
  > [!info] If \(K\) changes by factor \(n\), optimal \(Q\) changes by \(\sqrt{n}\). Same for \(H\).  

- **Lesson**  
  > [!warning] Lowering fixed/holding costs yields diminishing returns; focus on realistic cost estimates.

## 2. Cost classification (fixed vs variable)

| Cost type | Varies with order size? | Incurred if no production? | EOQ inclusion |
|-----------|------------------------|----------------------------|---------------|
| Lease (3‑yr, $1,000/mo) | No | Yes | **No** (fixed, sunk) |
| Holding cost (per unit) | Yes | No | Yes |
| Shortage cost | Yes | No | Yes |
| Ordering cost \(K\) | Yes (per order) | No | Yes |

- **Sunk‑cost principle**: ignore already incurred fixed costs when deciding future order quantities.  

- **Selling‑cost vs purchase‑cost**: discounts to clear old models are selling costs; they must be included in inventory decisions.

## 3. Newsvendor model (uncertain demand)

- **Key variables**  

  > [!info]  
  - \(Q\) = order quantity  
  - \(D\) = random demand (distribution \(F\))  
  - \(C_o =\) purchase price − salvage value (overage cost)  
  - \(C_u =\) selling price − purchase price (underage cost)  

- **Critical ratio (CR)**  

  > [!info] \(CR = \dfrac{C_u}{C_o + C_u}\) → desired in‑stock service level (probability demand ≤ \(Q^*\)).  

- **Optimal \(Q^*\)** (normal demand)  

  > [!info] \(Q^* = \mu + z_{\alpha}\sigma\) where \(z_{\alpha}= \Phi^{-1}(CR)\).  

- **Cost dominance**  
  - If \(C_o > C_u\) → bias **downward** (order < mean).  
  - If \(C_u > C_o\) → bias **upward** (order > mean).  

- **Worked example** (copy‑paper)  

  > [!example]  
  - Purchase $1, selling $1.50, salvage $3.30 → \(C_o = 1 - 3.30 = -2.30\) (negative, so overage cost is actually a gain).  
  - Underage cost \(C_u = 1.50 - 1 = 0.50\).  
  - CR = 0.50/(0.50‑2.30) → adjust accordingly; optimal order falls **below** mean (≈ 190 units vs. 200).  

## 4. Safety stock & service level (normal approximation)

- **Safety stock**: \(SS = Z \times \sigma\).  

- **Critical ratio to Z**  

  > [!info] Compute \(Z = \Phi^{-1}(CR)\) using Excel `NORM.S.INV(CR)` or a standard normal table.  

- **Effect of cost balance**  

  | Cost relation | CR | Z | Ordering rule |
  |---------------|----|---|----------------|
  | \(C_o \approx C_u\) | ≈ 0.5 | 0 | Order at mean (\(Q^*≈\mu\)) |
  | \(C_o \gg C_u\) | → 0 | negative | Order **below** mean |
  | \(C_u \gg C_o\) | → 1 | positive | Order **above** mean |

- **Example (SMU)**  

  > [!example]  
  - \(\mu=100\), \(\sigma=4.47\), \(CR=0.545\) → \(Z≈0.12\).  
  - Safety stock ≈ 0.54, \(Q^*≈100.54\).  

## 5. Decision workflow (step‑by‑step)

1. **Classify costs** – separate fixed/sunk from variable (holding, shortage, ordering).  
2. **Select model** – EOQ if demand deterministic; Newsvendor if demand stochastic.  
3. **Gather data** – export demand history, compute \(\mu\) and \(\sigma\).  
4. **Determine cost parameters** – calculate \(C_o\) and \(C_u\).  
5. **Compute critical ratio** \(CR = C_u/(C_o+C_u)\).  
6. **Find Z** – use normal inverse (or appropriate distribution).  
7. **Calculate optimal order** – EOQ formula or \(Q^* = \mu + Z\sigma\).  
8. **Place order** – align order frequency with demand (EOQ) or lead‑time considerations (newsvendor).  

> [!warning] Do **not** let fixed lease or sunk costs influence the \(Q^*\) calculation; they affect profitability but not the optimal order size.

## Key terms

| Term | Meaning |
|------|---------|
| EOQ | Economic Order Quantity; optimal order size for deterministic demand. |
| \(K\) | Fixed ordering cost per order. |
| \(H\) | Holding cost per unit per period. |
| Fixed (sunk) cost | Cost independent of order quantity; excluded from EOQ. |
| Over­age cost \(C_o\) | Cost of one unsold unit (purchase‑salvage). |
| Under­age cost \(C_u\) | Lost profit from a stockout (selling‑purchase). |
| Critical ratio (CR) | Desired service level = \(C_u/(C_o+C_u)\). |
| Safety stock | Buffer inventory = \(Z\sigma\). |
| \(Z\) | Standard‑normal quantile matching CR. |
| Newsvendor model | Inventory model for stochastic demand using overage/underage costs. |

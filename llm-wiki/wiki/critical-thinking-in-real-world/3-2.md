> [!summary] Key takeaways  
- Validity = guarantee: true premises make false conclusion impossible.  
- Deductive intent → aim for validity; inductive intent → aim for relative strength.  
- Sound = valid + all true premises; cogent = strong + all true premises.  
- Normative conclusions need a contested normative premise; descriptive conclusions can be uncontroversially sound.  
- Evaluate: intention → inference strength → premise truth → classify.

## 1. Inference Strength & Validity
- An inference may be **weak**, **strong**, or **maximally strong** (valid).  
> [!info] **Valid inference**: premises guarantee the conclusion; if premises are true, the conclusion cannot be false.  
- Validity and invalidity are mutually exclusive; an argument is never both.  
> [!warning] Do **not** use “valid” in its everyday sense—logic restricts it to the guarantee relation.  
- **Validity test**: assume premises true; is it *impossible* for the conclusion to be false? → Yes = valid; No = invalid.  
- Strength alone does **not** ensure validity; a strong inference can still be invalid.

## 2. Deductive vs. Inductive Intentions
- **Speaker’s intention** decides the argument type:  
  - **Deductive** → convince that the conclusion is *guaranteed* true.  
  - **Inductive** → convince that the conclusion is *highly likely* true.  
- Premises must be true in either case; false premises defeat the argument regardless of intention.  
> [!info] **Charitable interpretation rule**  
  - If the inference is **valid**, read the argument **deductively**.  
  - If the inference is **relatively strong but not valid**, read it **inductively**.  

## 3. Argument Classifications & Evaluation Steps
| Step | Question | Outcome |
|------|----------|---------|
| 1 | What certainty level does the speaker aim for? | Deductive (guarantee) or Inductive (likelihood) |
| 2 | Is the inference **valid** or merely **relatively strong**? | Valid → deductive; Strong → inductive |
| 3 | Are **all premises true**? | Yes → proceed; No → argument unsound/uncogent |
| 4 | Classification | **Deductive + valid + true** → **Sound**; **Inductive + strong + true** → **Cogent**; otherwise **Unsound** or **Uncogent** |

- **Sound argument**: valid inference + all true premises (gold standard).  
- **Cogent argument**: relatively strong inference + all true premises.  
- **Unsound/Uncogent**: any false premise or invalid/weak inference.

## 4. Normative vs. Descriptive Conclusions
- **Descriptive (‑is) claims** can be supported by uncontroversial sound arguments.  
- **Normative (‑ought) claims** require at least one **normative premise** linking facts to the ought‑statement.  
> [!example] *Smoking is injurious* (is‑claim) does **not** alone justify *You should not smoke* (ought‑claim) without the principle “If something is harmful, one ought not to do it.”  
- Disagreements over normative conclusions usually stem from disagreement over the **normative principle**, not from logical validity.  
- To challenge a normative argument, attack either:  
  1. The factual premises (e.g., “Abortion is murder”).  
  2. The normative principle connecting facts to the ought‑statement.  
- Begging the question (assuming the needed principle) renders the argument unpersuasive.

## 5. Soundness, Cogency, and Common Pitfalls
- **Soundness** = validity + truth of all premises. Guarantees the conclusion.  
- **Cogency** = relative strength + truth of all premises. Makes the conclusion probable.  
- An argument that merely restates its premises adds no new information; the conclusion is already known.  
- Personal/aesthetic judgments (e.g., “Mondrian paintings are ugly”) are preferences, not normative claims requiring logical justification.  
- Social‑policy claims (e.g., “Girls should go to school in Afghanistan”) hinge on contested normative principles about education and gender.

## 6. Worked Example: Problem of Evil (Deductive)
> [!example]  
1. If God exists, He is all‑powerful, all‑knowing, and all‑good.  
2. If God has those attributes, there should be no evil.  
3. Evil exists.  
4. Therefore God does not exist.  

- The inference is **deductively valid**: true premises make the conclusion unavoidable.  
- To reject the conclusion, one must deny at least one premise (commonly premise 2, by allowing a good God to permit evil for free‑will reasons).

## 7. Communication Clarity (Brief Note)
- Effective description eliminates vagueness; precise verbal specifications (e.g., “0.5 cm left and right”) enable accurate reconstruction of a figure.  
- In argument analysis, clarity of premises and inference steps is equally essential.

## Key terms
| Term | Meaning |
|------|---------|
| **Valid inference** | Premises guarantee the conclusion; false conclusion impossible if premises true. |
| **Sound argument** | Valid inference + all premises true; conclusion necessarily true. |
| **Cogent argument** | Relatively strong inference + all premises true; conclusion highly probable. |
| **Normative principle** | Premise that bridges descriptive facts to an ought‑statement. |
| **Charitable interpretation** | Reading a valid inference as deductive and a strong-but-invalid inference as inductive. |
| **Begging the question** | Assuming the very principle one needs to prove; circular reasoning. |

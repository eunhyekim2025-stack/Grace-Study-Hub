> [!summary] Key takeaways
- Identify an argument’s structure (premises → inference → conclusion).  
- Refute by attacking false premises or weak inferences, not merely the conclusion.  
- Use probability shifts to decide whether a statement attacks a premise, inference, or conclusion.  
- Diagram with solid (support) and dotted (attack) arrows to make weak points visible.  
- Distinguish inductive vs deductive arguments; only sound deductive arguments guarantee the conclusion.

## 1. Argument Structure & Evaluation
- **Deductive**: valid inference + true premises = sound; guarantees the conclusion.  
- **Inductive**: premises make the conclusion probable, not certain.  
- **Validity**: premises are sufficient to guarantee the conclusion.  
- **Relative strength**: premises increase confidence but can be weakened by new information.

## 2. How to Refute an Argument
- Must target **premises** or the **inference**; merely denying the conclusion is insufficient.  
- Spot unsupported premises (e.g., Grayling’s Premise 2: “reasonable drug use does not damage the social fabric”).  
- Identify weak inductive moves (e.g., “no important difference” between legal drugs and other activities).

## 3. Types of Attacks
| Target | What to test | How to test |
|--------|--------------|-------------|
| Premise | Truth of the statement alone | Assign baseline probability; add alleged attacker → does probability drop? |
| Conclusion | Likelihood of conclusion alone | Same probability test, ignoring surrounding premises |
| Inference | Strength of link between premises & conclusion | Evaluate support before/after adding attacker; keep argument context |

- Use **solid arrows** for support, **dotted arrows** for attacks in diagrams.

> [!info] Attack Test Procedure  
1. Set baseline probability for the target (premise or conclusion) in isolation.  
2. Introduce the alleged attacking statement as true.  
3. If the probability decreases, the statement is an **attack** on that target.

> [!warning] When testing attacks on premises or conclusions, treat the target **out of context**; only attacks on inferences require the full argument context.

> [!example]  
Premise: “Albert is rich.” Baseline 50%.  
Attacker: “Albert is blind.” Probability unchanged → **not** an attack.

## 4. Diagramming Arguments
- **Arrow diagram**: Premises → Inference → Conclusion.  
- **Solid arrow** = support; **dotted arrow** = attack.  
- *Example*: Grayling’s drug‑legalization argument (Premise 1, Premise 2 → Conclusion).  
  - Counter‑example (smoking in non‑designated areas) attacks Premise 2.  
  - Statement 9 attacks the inference (5 + 6 → 7) because that inference is only relatively strong.

## 5. Ambiguity & Charitable Representation
- **Charitable interpretation**: reproduce the opponent’s argument accurately, without adding or omitting points.  
- Avoid inferring motivations unless explicitly stated.  
- Distinguish **lexical ambiguity** (different word meanings) from **structural ambiguity** (different parses).  
  - “Only lusts after Emma” can support a desire claim or, if read as “only lusts after Emma and does not love her,” attack a love claim.

## 6. Practical Illustrations
- **Parking on a double‑yellow line**: non‑harmful behavior yet criminalized → challenges the premise that only harmful conduct should be illegal.  
- **Not wearing a mask during a pandemic**: clearly harms others → supports a premise that some private behavior does damage third parties.

## Key terms
| Term | Meaning |
|------|---------|
| Deductive argument | Inference where true premises guarantee the conclusion; sound if premises are true. |
| Inductive argument | Inference where premises make the conclusion probable but not certain. |
| Validity | Logical form where premises are sufficient for the conclusion. |
| Relative strength | Degree to which premises support a conclusion; can be weakened by new info. |
| Attack (premise/inference/conclusion) | A statement that lowers the probability of the target when added. |
| Charitable interpretation | Representing an opponent’s argument accurately and fairly. |
| Arrow diagram | Visual map of premises, inference, conclusion with solid (support) and dotted (attack) arrows. |

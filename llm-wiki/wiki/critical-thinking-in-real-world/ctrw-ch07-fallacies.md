# Ch7 — Fallacies

> [[index|← Critical Thinking in Real World]] · Textbook Ch.7 (the longest). A field guide to bad reasoning. Exercises **7.1–7.3** (private answer key held for feedback — explaining *why* each is/ isn't fallacious matters as much as the label).

## Family 1 — Fallacies of irrelevance (*ignoratio elenchi*)
Premises with no logical bearing, dressed up with a *psychological* pull — by focusing on **who, when, why or how** rather than the substance.

| Fallacy | The move | Legitimate when… |
|---|---|---|
| **Appeal to Pity** (*ad misericordiam*) | "feel sorry for X, so X's claim is true" | pity is relevant to the *punishment*, not to guilt |
| **Appeal to Popularity** (*ad populum*) | "most people believe/do X, so X is true/right" — incl. **Appeal to Tradition** ("we've always done X") | popularity *constitutes* the fact — etiquette, convention (bowing in Japan, driving side) |
| **Ad Hominem — Abusive** | attack the arguer's character, not the argument | the flaw is *logically relevant* (a **drunk** who talks nonsense; a **sadist** for the animal shelter) |
| **Ad Hominem — Circumstantial** | "X has a motive/interest, so ignore X's argument" | you're weighing an **unsupported claim** (a tobacco baron's *say-so*), not a stated argument |
| **Ad Hominem — Tu Quoque** ("You Too") | "X doesn't practise what X preaches, so X is wrong" | the point *is* to call out **hypocrisy** itself (not to reject the claim) |
| **Straw Man** | misrepresent the opponent's argument as a weaker one, then knock *that* down | never — there are always **two** arguments and it is *always* fallacious |
| **Red Herring** | distract with an attention-grabbing side-claim, or just ramble, so the promised argument never arrives | never (the conclusion to be shown sits at the *start* of the passage) |
| **Appeal to Ignorance** (*ad ignorantiam*) | "not proven false, so true" / "not proven true, so false" | reliable tests **would have** found the evidence and didn't (a careful medical negative) |
| **Rejecting the Conclusion of a Bad Argument** | "your reasons for C are bad, so C is false" | never — you can argue *badly for a true* conclusion |

> **Straw Man vs Red Herring:** Straw Man = *two* arguments, one distorting the other. Red Herring = *one* argument that quietly proves a *different* conclusion.

## Family 2 — Fallacies of weak induction
The premises are relevant but **too thin** to make the conclusion likely.

| Fallacy | The move | The probe |
|---|---|---|
| **Suppressing Information** | omit known info that would weaken your claim (or strengthen the opponent's) | is relevant evidence being *hidden*? (one of the most serious — it subverts the point of argument) |
| **Hasty Generalisation — Biased Sample** | generalise from an **unrepresentative** sample | was sampling **random / uniformly distributed**? relate the method to what's studied |
| **Hasty Generalisation — Small Sample** | generalise from **too few** cases (anecdote) | is *n* large enough for the population's homogeneity? anecdote supports only *modest* conclusions |
| **Exception Proves the Rule** | "one exceptional case, so it's generally so" (the parachute survivor; the 93-year-old smoker) | a sub-case of Small Sample — one exception ≠ the general rule |
| **Appeal to Unqualified Authority** (*ad verecundiam*) | "expert/celebrity says X, so X" | is the source a **genuine, on-topic, unbiased** authority? (a basketball star on cologne is neither) |
| **Post Hoc** (*after this, so because of this*) | "B happened just after A, so A caused B" | mere temporal order isn't causation (the crow and the fall) |
| **Cum Hoc** (*with this, so because of this*) | "A correlates with B, so A causes B" | correlation ≠ cause; could be coincidence or a third factor |
| **Mistaken Cause** | assume a cause-effect relation but get the **direction** wrong or miss a **common cause** | could B cause A? could C cause both? (smoking ↔ poor exam results) |
| **Causal Slippery Slope** | "doing X triggers a chain ending in disaster (or utopia)" | is a **link unlikely**, or the **chain so long** that all steps together are improbable? |
| **Weak Analogy** | "X and Y share a,b,c, so Y also has z" | are the shared properties **relevant** to z? any strong **disanalogy**? (car *colour* ≠ speed; "Kelly is a man") |

## Family 3 — Fallacies of presumption
An assumption you're **not entitled to** is taken for granted.

| Fallacy | The move | Note |
|---|---|---|
| **Begging the Question — Omission of Premise** (*petitio principii*) | leave out the **controversial** premise the conclusion needs ("abortion is wrong — we can't condone murder of the innocent") | only a fallacy if the missing premise is *controversial*; an obvious one ("chickens are animals") is fine |
| **Begging the Question — Restatement** | give a "reason" that just **restates** the conclusion in other words | no *independent* reason has been given |
| **Begging the Question — Circular Chain** | a chain of premises that loops back to **presuppose** the conclusion (Bible↔God) | *causal feedback* (share prices↔buying over time) is **not** circular — different events at different times |
| **Complex Question** | a yes/no question with an unfair **loaded** second question baked in ("Have you stopped smoking?") | the *question* alone isn't a fallacy — only when an **argument** is built on the forced answer |
| **False Dichotomy — Overlooking Alternatives** | "P or Q; not P; so Q" where **other options** were ignored | valid in *form* (disjunctive syllogism) yet fallacious in *content* — the "or" doesn't exhaust the options |
| **False Dichotomy — Overlapping Alternatives** | "P or Q; P; so not Q" where **both** can hold | invalid — the disjuncts aren't exclusive (Irish *and* Australian passport) |

> A **genuine dichotomy** (options exhaust the space *and* don't overlap) is not a fallacy; and a disjunction can fail *either* test — or, charitably read, be fine ("Harry's in London or Paris… so not London").

## Family 4 — Miscellaneous (ambiguity & whole/part)

| Fallacy | The move |
|---|---|
| **Equivocation** | a key word shifts meaning between premises ("*laws* of nature" → "*laws* of an authority"; "*abnormal*" = unusual → defective) |
| **Missing Comparative** | "better / faster / healthier" with no "**than what?**" stated |
| **Composition** | infer the **whole** has a property because its **parts** do |
| **Division** | infer a **part** has a property because the **whole** does |
| **Accident** | apply a **general rule** to a genuine **exception** it wasn't meant to cover |
| **Semantic Slippery Slope** | exploit a term's **vagueness** to slide from clear cases to unclear ones (sorites) |

## Key takeaways
- A fallacy is defective **reasoning** — not merely a false premise, a false conclusion, or a non-argument; and a **true conclusion never rules a fallacy out**.
- Learn the four families by their **tell**: irrelevance (who/why/how), weak induction (thin evidence/bad causation), presumption (unearned assumption), ambiguity (word or whole/part shift).
- **Context can redeem the "move"** — relevant character, relevant pity (to punishment), reliable absence-of-evidence, causal feedback (not circular), genuine dichotomy.
- To flag a fallacy, **name it *and* explain why it fails here** — the explanation is the real work.
